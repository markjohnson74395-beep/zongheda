# 同一台电脑别人 60 帧我只 20 帧：雷电模拟器性能设置里真正起作用的 4 个参数和调优顺序

上个月把笔记本搬到同事工位，两个人并排跑同一个手游，画质选项一模一样，他右上角稳在 60，我这边数字在 19 到 23 之间跳。配置也不至于差这么多——他 i5 加 16G 加一张入门独显，我 i7 加 16G 加同代独显，纸面上我还占优。

先按常识排查：驱动是最新的，后台没挂东西，风扇也在转。翻车的地方在模拟器自己的设置面板里——VT 没开，显卡渲染被自动挑成了兼容模式，分辨率跟着我的 2K 屏一路拉到 2560×1440，帧率上限还老实停在 30。四个参数一个都没对，帧数自然对不上。这篇把四项拆开讲，再给一套能照着走的顺序，先动哪个后动哪个差别很大。想先看图文对照的，[雷电模拟器性能设置分项说明](https://vibez-store.com) 里有截图版。

## 一、先把差距归到参数上，别急着怪硬件

20 帧和 60 帧之间隔着三倍算力，这个量级不太可能是"CPU 差一代"造成的。模拟器等于在一台机器里跑两套系统，瓶颈位置固定，而且都能在设置里看到：

| 参数 | 常见错误状态 | 它决定什么 | 合理起点 |
| --- | --- | --- | --- |
| **VT 虚拟化** | BIOS 里没开，或被 Hyper-V 抢占 | 决定模拟器是"原生速度"还是"软件翻译"，差得最多的一项 | 任务管理器里显示"已启用" |
| **显卡渲染模式** | 停在兼容模式 / OpenGL 自动回退 | 画面由谁画：独显直通，还是 CPU 软件渲染 | OpenGL 或 DirectX，逐次试 |
| **分辨率与 DPI** | 跟着显示器拉到 2K、4K | 像素数量，直接乘在渲染开销上 | 1280×720，DPI 240 |
| **帧率上限** | 停在 30，或盲目拉到 120 | 目标帧，但天花板受上面三项限制 | 60，稳了再往上 |

对着这四行自查一遍，通常能解释掉八成"我这台为什么卡"。

## 二、VT：不是"开了就行"，是"别被抢占"

VT 是地基。没开的时候不是慢一点，是直接换了一套运行方式，所有指令多绕一层，帧数腰斩很正常。

判断方法很快：`Ctrl+Shift+Esc` 打开任务管理器 →「性能」→ 点「CPU」，右下角有一栏「虚拟化」，显示"已启用"才算过。显示"已禁用"，就是 BIOS 里那一项没开（Intel 平台叫 VT-x，AMD 平台叫 SVM，一般在 Advanced 或 CPU Configuration 里）。

开了 VT 还卡的话，看第二个地方——**虚拟化能力可能被 Windows 自己占着**。按 `Win+R` 敲 `msinfo32`，看最下面「基于虚拟化的安全性」，如果状态是"正在运行"，说明 Hyper-V 那一套正在吃这块能力。处理方式是：

1. 控制面板 →「程序」→「启用或关闭 Windows 功能」；
2. 取消勾选 Hyper-V、虚拟机平台、Windows 虚拟机监控程序平台；
3. 重启；
4. 回到 `msinfo32` 确认状态变成"未启用"，再启动模拟器对比帧数。

Windows 11 还有一处容易漏：「Windows 安全中心」→「设备安全性」→「内核隔离」→ 把「内存完整性」关掉，重启。这两项都开着的时候，模拟器甚至可能起不来，弹一句 VT 相关的提示。关完还想用 WSL2 或 Docker 的，注意它们和模拟器抢的是同一份能力，得二选一。

## 三、显卡渲染模式：三种模式不是版本高低

打开模拟器的「设置」→「性能设置」，能看到「显卡渲染」的下拉框。很多人以为越靠下的越新、越好，实际是三个不同路线，跟你的显卡型号和驱动版本匹配度有关：

| 渲染模式 | 适合谁 | 出问题时的典型症状 |
| --- | --- | --- |
| **OpenGL** | 大多数独显，兼容面最广 | 少数新驱动下会花屏或黑屏一瞬 |
| **DirectX** | N 卡、A 卡较新驱动，帧数上限更高 | 老驱动上可能出现贴图错位 |
| **Vulkan** | 较新显卡，长时间高帧更稳 | 部分老游戏直接黑屏、闪退 |
| **兼容模式** | 只在前面几种都起不来时用 | 画面正常但帧数极低，全靠 CPU 顶 |

我这次的坑就落在「兼容模式」那一行。装机时默认落到了兼容模式，看着能跑，实际是 CPU 在拿软件方式画每一帧。切到 OpenGL 重启模拟器，同一个场景从 20 帧到 47 帧，这一步的收益比后面三项加起来都大。

切完要**完整重启模拟器**才生效，只关窗口不算。花屏、闪退、黑屏就换下一个模式试，三个都不行再回兼容模式，然后从驱动版本上找原因。各模式与显卡、驱动版本的对应关系，[雷电模拟器显卡渲染与性能设置对照](https://vibez-store.com) 里按显卡分类列过，懒得一个个试的可以照表跳。

## 四、分辨率：先降像素，再谈帧数

分辨率是最容易被忽略的一项，因为它藏在「性能设置」里，默认还跟着显示器走。2560×1440 的像素量是 1280×720 的四倍，这份开销全压在渲染上，帧数掉一半不奇怪。

面板里有两个东西要一起改：**分辨率**和 **DPI**。分辨率给 1280×720，DPI 给 240，这是手感和大小的平衡点；觉得字太小，DPI 往 160 调，别反过来去拉分辨率。想吃鸡、打射击类要更清楚的，1600×900 是下一档，再往上就要看显卡脸色了。

还有个细节：模拟器右上角有「平板版 / 手机版」的切换。某些游戏在平板模式下会按大屏渲染 UI 和场景，等于你自己把像素量又抬了一档。玩游戏就切手机版，只有看文档、刷网页才用平板版。

## 五、帧率上限：60 是起点，不是目标

帧率上限在「设置」→「游戏设置」里。这里有两个反直觉的地方。

一个是**上限低于能力**时反而更难受。上限设 30，帧数就在 28 到 30 之间抖，体感比稳 45 还差。先把上限放到 60，让模拟器有余量，实际帧数会稳得多。

另一个是**上限高于能力**纯属自找麻烦。拉到 120 而实际只有 50，多出来的目标只会让帧生成节奏更乱。判断标准很简单：上限设成 60 跑十分钟，看帧数能不能贴着 60 走；能贴住再试 90，贴不住就往回退到 45 或 30，别硬撑。

想直接看帧数，在「其他设置」里打开帧率显示，游戏画面角上会常驻一个数字，比凭感觉判断靠谱。显示器只有 60Hz 的，上限拉到 120 不会有任何收益。

## 六、CPU 和内存：给系统留一口

同一个面板里还有 CPU 核心数和内存，这是唯一"给多了反而变慢"的地方：核心全划给模拟器，Windows 自己调度不上，鼠标都会发飘。16G 机器 4 核 / 4096MB 起步，8G 机器 2 核 / 2048MB；挂机多开按实例数往下压，别每个都给满。改完同样要重启实例。

## 七、一次完整的调优顺序

参数之间互相影响，顺序错了会白折腾。我自己的走法是按"地基在前、效果在后"排的，一次只动一项，动完跑同一段场景对比：

1. 任务管理器确认「虚拟化：已启用」，`msinfo32` 确认「基于虚拟化的安全性」未运行，Hyper-V 与内存完整性都关掉，重启；
2. 模拟器「设置」→「性能设置」，显卡渲染切到 OpenGL，完整重启模拟器；
3. 同一面板把分辨率设成 1280×720、DPI 240，模式切手机版，重启实例；
4. 「设置」→「游戏设置」把帧率上限设到 60，打开帧率显示；
5. 「性能设置」里 CPU 4 核、内存 4096MB，再重启一次；
6. 跑十分钟常玩的那张地图，记下平均帧和最低帧；
7. 还有余量再动分辨率（1600×900）或帧率上限（90），一次只改一项。

每改一步都记下数字，这样能明确知道是哪一项起了作用。凭感觉调很容易把功劳记错，换台机器又要从头试。

## 八、调完还卡，往这三个方向看

**驱动版本**。模拟器对新驱动的适配有滞后，最新的驱动不一定最合适。往前退一到两个大版本试，比在设置里反复折腾有效。

**散热降频**。笔记本尤其明显，插电和不插电是两个性能档，跑十分钟后帧数一路下滑，多半是温度墙。垫高、清灰、把电源模式调到高性能，先排除这一项再去改参数。

**后台占用**。浏览器开几十个标签、录屏软件、同步盘，抢的是同一份 CPU 和显存。挂机时把窗口最小化、关掉不用的后台，效果常常比调参数更直接。

## 九、调完这四项，再决定要不要换硬件

同一台机器，四个参数调对之后我从 20 帧到 58 帧，硬件一个螺丝都没动。所谓"模拟器吃配置"，吃的是那几项关键设置有没有落到对的位置上；VT 被抢占、渲染掉进兼容模式、分辨率跟着显示器跑、帧率上限停在 30，这四种状态里任何一种都足够把 60 帧打成 20 帧，而它们全都跟你的 CPU 型号无关。

动手时照第七节的顺序走，改一项验一项。设置项位置、渲染模式对应关系、VT 冲突的处理步骤，[雷电模拟器使用与性能优化说明](https://vibez-store.com) 里都留了分步截图。真调完还是卡在同一条线上，再去看显卡和内存，那就是有依据的升级了。
