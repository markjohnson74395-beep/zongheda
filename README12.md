# 四个人的浏览器菜单长得都不一样：Chrome、Edge、Safari、Firefox 清缓存的准确路径对照（附 9 个最容易点错的菜单项）

上周三下午，运营组四个人把笔记本推到我桌上，说的是同一句话："帮我把缓存清一下。"

我一台一台点过去，才发现这四个人的浏览器菜单长得完全不一样。小陈的 Windows Chrome，得点右上角三个点、在竖排列表里数到第九项才看见「清除浏览数据…」；阿哲的 Edge 是「设置 → 隐私、搜索和服务」，还要再滚半屏才摸到「选择要清除的内容」；用 Mac 的编辑连快捷键都借不上，得先去菜单栏找「Safari → 设置 → 隐私 → 管理网站数据…」；剩下一台 Firefox 倒痛快，`Ctrl + Shift + Delete` 一按，弹出的小窗标题叫「清除最近的历史记录」。

同一个动作被起了四个名字、藏在四个层级、用四种方式确认。我把路径抄在便签上贴到显示器边才想明白：难的不是"清"，是"找到那个按钮"，以及"看着名字以为找对了"。

这篇只钉路径，到菜单项级别。清完登录要重扫、清了还打不开往哪一层查，站内 [浏览器缓存清理指南](https://tlgrpv-web.com) 另有按症状分的入口。

## 三条判断线，比记路径管用

路径会随版本挪位，这三条不会变：清缓存和清登录永远是两个勾选框，名字对不上就按"带缓存字眼的那个"认；时间范围永远在面板最上面那行，四家默认值各不相同；只清单个站点，走地址栏左边那个图标。

## 路径对照表：从打开到点确认，各走几步

| 浏览器 | 入口（层数） | 面板或窗口名字 | 要勾的那一项 | 时间范围默认 |
| --- | --- | --- | --- | --- |
| Chrome | ⋮ →「清除浏览数据…」，2 层 | 清除浏览数据 · 分「基本 / 高级」标签 | 缓存的图片和文件 | 过去 1 小时 |
| Edge | ⋯ →「设置」→「隐私、搜索和服务」→「选择要清除的内容」，5 层 | 清除浏览数据 · 顶部是时间范围下拉 | 缓存的图片和文件 | 全部时间 |
| Safari | 菜单栏「Safari → 设置 → 隐私 → 管理网站数据…」，4 层 | 管理网站数据（带搜索框的弹窗） | 无勾选项，靠「移除」 | 不适用 |
| Firefox | `Ctrl + Shift + Delete` 直达，或 ≡ →「历史」→「清除最近的历史记录…」 | 清除最近的历史记录（独立小窗） | 临时缓存的网页内容（旧版写「缓存」） | 最近一小时 |

三处结构差异值得记住：Chrome 和 Edge 把选项切成「基本 / 高级」两个标签，你要的在默认那页；Firefox 平铺所有项目；Safari 根本没有"缓存"这个勾选项——最多人在这里空手而归。

## Chrome：三下点完，第九项不一定在第九位

点开右上角 `⋮`，往下数：新标签页、新窗口、新无痕窗口、历史记录、下载内容、书签和清单、标签页群组、扩展程序、清除浏览数据…——右边还印着浅灰的 `Ctrl + Shift + Delete`，那行提示本身就是确认方式。

进去是「清除浏览数据」页面，默认停在「基本」标签，只有三项：浏览历史记录、Cookie 及其他网站数据、缓存的图片和文件。**第三项才是你要的**，前两项都是登录状态的邻居，手滑勾上就等着重新扫码。「高级」标签里是密码、自动填充、网站设置那一堆，日常用不到，只有「网站设置」值得看一眼——之前拒过某站的通知或摄像头，清掉它能复位权限。

Mac 上位置相同，快捷键换成 `Cmd + Shift + Delete`，只是部分版本这一项落到第 11 位，夹在「投放」和「查找」之间。找不到就用地址栏兜底：输入 `chrome://settings/clearBrowserData` 回车直接落地。

## Edge：路径最长，还多一个常开开关

`⋯` →「设置」，默认落在「隐私、搜索和服务」，往下滚先看到「每次关闭浏览器时要清除的内容」这个开关列表，**再往下**才是「立即清除浏览数据」和它的「选择要清除的内容」按钮。上面那个区块长得更像正主，我在这块来回滚过三遍；它也能直接当自动清理用，只勾缓存不勾 Cookie，等于每次关窗擦一遍资源副本。

点进去的面板和 Chrome 几乎一样，只是时间范围默认落在「全部时间」，比 Chrome 狠一档。切到「全部时间」的一瞬间下面会多出两行勾选项，「下载历史记录」这类只在全时段才出现。

## Safari：没有快捷键，缓存还藏在开发菜单里

Mac 上先接受一件事：**Safari 的「清除历史记录…」（`⌘⇧⌫`）不等于清缓存**，它删的是浏览记录，资源缓存不动，页面该错乱还是错乱。真正的两条路：

1. 打开「Safari → 设置」（Ventura 之前叫「偏好设置」，位置一样）。
2. 切「隐私」标签，点「管理网站数据…」，弹窗带搜索框，站点按占用空间从大到小排。
3. 搜索框输入域名，选中那一行点「移除」——只清这一个；点「移除全部」全站登录一起走。
4. 清全部缓存要回菜单栏「开发 → 清空缓存」。它默认是灰的，甚至整个「开发」菜单都看不见，得先去「设置 → 高级」底部勾上「显示网页开发者功能」。
5. 顺手看「网站」标签页，摄像头、通知授权在那里，清完数据会退回「询问」，扫码前记得先给摄像头。

iPad 入口不同：「设置 → Safari → 高级 → 网站数据」，没有开发菜单，缓存只能靠关标签页或整体重置，后者会带走登录。

## Firefox：唯一还留着独立小窗口的一家

`Ctrl + Shift + Delete` 直接弹出「清除最近的历史记录」小窗，第一行是「要清除的时间范围」下拉：最近一小时、今天、全部。下面竖排六个复选框：浏览和下载历史、Cookie 和网站数据、临时缓存的网页内容、表单和搜索历史、站点设置、离线网站数据。

第三项的名字是关键。Firefox 128 前后把这一项从「缓存」改成「临时缓存的网页内容」，同一台机器升一次级就对不上教程里的字；看到它就等于旧版的「缓存」，勾它，别顺手勾紧挨着的「Cookie 和网站数据」。

## 只想清单个站点：那个图标四家长得不一样

Chrome 是调谐器样式的图标（旧版是灰锁），点开叫「网站设置」，底部有「删除数据」；Edge 是锁形，标题「此站点的权限」，Cookie 那行右边有垃圾桶图标；Firefox 是盾牌或锁，点开有「清除 Cookie 和站点数据」；Safari 只有一个「aA」图标，菜单里才藏「网站设置…」。

勾到站点数据的话，页面会跳出「会话已过期，请重新登录」，二维码重新出现——不是故障。

## 九个最容易点错的位置

1. Chrome 的「Cookie 及其他网站数据」和「缓存的图片和文件」只隔一行。
2. Chrome 时间范围默认「过去 1 小时」，实际只清了一小时内的副本。
3. Edge 那个开关列表比真正的清理按钮更像入口。
4. Edge 默认「全部时间」，一次点击的代价比你以为的大。
5. Safari 的「清除历史记录…」被当成清缓存用了很多年。
6. Safari 的「移除全部」和「移除」只差两个字，后果是全站登录清空。
7. Firefox 的「缓存」改名「临时缓存的网页内容」，照老教程会以为没了。
8. 单站点清理藏在地址栏图标里，去设置页翻找不到。
9. 清完只按 `F5` 不够，内存里还留着副本，得 `Ctrl + F5`（Mac 为 `Cmd + Shift + R`）强制重载。

## 版本挪位备忘：几条我实际撞过的位移

Chrome 121 之后设置首页一度把「隐私和安全」「安全和隐私」混用，进去后其实还是「删除浏览数据」那一页，跟旧的「清除浏览数据」是同一个。Edge 改侧边栏那次把「隐私、搜索和服务」从折叠项提成顶层第一项，按记忆点十次有三次落在「外观」上；Firefox 128 收窄了那个小窗，六个复选框要滚动才看得全，「离线网站数据」很容易漏。站内按浏览器分列的 [各浏览器使用建议](https://tlgrpv-web.com) 就是按这套版本差异维护的。

## 路径会挪位，判断标准只有两条

一年点下来结论很朴素：**路径记三个月就会过期，判断标准能用三年。** 标准只有两条——你勾的那一项名字里带"缓存""临时""图片和文件"，而不是"Cookie""站点数据""登录"；清完必须强制重载一次，普通刷新看不出效果。

守住这两条，菜单怎么搬家都不慌。找不到入口就在地址栏敲 `chrome://settings/clearBrowserData`，或者按 `Ctrl + Shift + Delete` 试试，四家里有三家认这个组合键；不认的那家去菜单栏第一个应用名底下的「设置」里翻，Safari 永远在那里。四套路径和版本变化对着看，[Telegram 网页版中文使用指南](https://tlgrpv-web.com) 的浏览器分区都留着图。
