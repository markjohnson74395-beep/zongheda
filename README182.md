## **一、先把底线立住：登录这一步，不该出现"密码"**

这是全篇最值钱的一条，记住它能挡掉九成钓鱼页面。

**Telegram网页版** 只有两条登录路：**手机扫二维码确认**，或者**手机号 + 验证码**。全程不需要你输入账号密码。唯一会出现"密码"的地方是**两步验证**——而且顺序很明确：你已经输完验证码、界面已经是熟悉的 Telegram 界面了，它才让你填那个自定义密码。

所以判断标准极其简单：

- 一上来刚输完手机号就要"账号密码"的 → 关掉，这是仿站。
- 让你"粘贴完整验证码到网页里"、"把收到的短信转发给客服" → 关掉。
- 提到"账号异常需缴纳解封费"、"提供身份证正反面核验"、"输入银行卡验证身份" → 关掉。
- 要你装一个"网页版专用客户端""加速插件"再登录 → 关掉。

> **说明**：网页版的登录凭证本质是浏览器里的会话（Cookie）。谁拿到它，谁就等于拿到了你这台设备上的登录态——所以"别乱输"和"用完退干净"是同一件事的两头，光做一头没用。

## **二、仿站识别：四个当场就能验的动作**

仿站不会做得粗糙，反而常常比原版更"正规"：多个盾牌图标、多一行"安全加密"、多一个客服悬浮窗。所以别靠观感判断，靠动作。

| 检查动作 | 具体怎么做 | 仿站通常会露馅的地方 |
| --- | --- | --- |
| **逐字符读域名** | 在地址栏点一下，从头读到尾，别只看前半段 | 形近字符替换（`l` 换 `1`、`rn` 换 `m`）；拼一个 `-web`、`-login` 后缀；`.com` 换成 `.cc`、`.top` |
| **看证书归属** | 点地址栏的锁，看证书颁发给哪个域名 | 域名对不上、用的是免费证书、页面里还混着一堆 http 资源 |
| **看它是怎么来的** | 自己敲地址，或从自己的收藏夹进 | 从群聊、私聊、搜索结果推广位、短链跳进来的——这是最大的入口风险 |
| **看它要不要"多余的东西"** | 只要出现密码框、粘贴框、客服要码，立刻停 | 一上来就要账号密码；验证码要求"转发给在线客服"；催你"30 秒内完成" |

我最看重第三条。**同一个页面，你手敲进去是干净的，别人发链接给你就未必是**——仿站从来不做 SEO 抢排名，它靠的是转发和广告位。所以我的做法是：把入口存进收藏夹，之后一律从收藏夹进，群里谁发的链接都不点，包括"朋友转的"。

## **四、从入口到登录：一条能走通的核对流程**

### **第一步：入口自己给，不要别人给**

浏览器地址栏手敲，或者从收藏夹点 [Telegram网页版入口](https://tlgrss-web.com)。进去第一眼看三件事：`https` 有没有、域名对不对、页面是不是直接给二维码或手机号登录框。如果它先让你"登录以继续浏览"，那是内容站的逻辑，不是登录页的逻辑。

### **第二步：扫码前先确认手机端在线**

打开手机 Telegram，随便点个聊天确认能收发。这一步不是多余——手机端被系统清了后台，你扫完码也收不到确认推送，接下来很容易被"不如用手机号"的念头带偏。

### **第三步：扫码后核对那张确认卡片**

扫完手机弹出一张卡片，写着**设备类型、浏览器名称、大致登录地点**。这张卡片是整条链路里唯一由你自己掌控的一步，别闭眼点确认。

- 地点跟你现在的位置对不上 → 拒绝，然后去"设置 → 设备"把陌生设备踢掉。
- 浏览器名称是你不认识的（你明明在用 Edge，卡片写 Chrome）→ 同样拒绝。
- 连着弹好几次确认 → 说明有人在反复尝试，先改两步验证密码。

### **第四步：登进去之后，先看设备列表**

别急着聊天。第一件事是进"设置 → 设备"，把当前所有登录设备过一遍。**你认得每一台，才算这次登录是干净的**；多出你不认识的，按第五节处理。

## **五、登录异常：三种征兆，按这个顺序查**

被盗号往往不是"突然登不上"，而是先有一堆小异常被你忽略掉。

**三种典型征兆：**

1. 手机突然收到一条你没发起的登录确认推送（哪怕是"拒绝"过的）。
2. 消息显示已读，但你没读；或者联系人问你"你刚才发的那条是什么"。
3. 设备列表里出现陌生设备、陌生会话，或者两步验证密码莫名其妙被改。

**排查顺序，别跳步：**

1. **先踢设备**。设置 → 设备 → 逐个终止陌生会话，这一步比改密码更急，因为它立刻切断对方。
2. **再改两步验证密码**。改成自己没在别处用过的，别用浏览器自动生成的弱口令。
3. **然后查授权**。看有没有你不认识的第三方应用拿到过权限，有就撤销。
4. **最后才动密码和邮箱**。顺序反了会给自己制造麻烦——很多人在第 4 步折腾半天，对方还在设备列表里挂着。

另外，如果你发现登录时总被要求"再验证一次"、验证码又老收不到，可能是有人在别处反复试你的号。别疯狂重发验证码，等一两个小时换条线路再来，顺手清一遍设备列表。

## **六、公用电脑和共享设备：退干净的四个动作**

我出差那次之后，把"收尾"也做成固定动作了。只关标签页不算退出——会话还挂在 Cookie 里，下一个人打开就能进。

1. **主动点退出登录**，别用关窗口代替。
2. **清 Cookie 和站点数据**，顺手把缓存也清了。这一步会连登录状态一起清掉，正好。
3. **关掉"记住密码"和自动填充**。这类功能是给普通表单设计的，用在登录页上等于把凭证留在机器里。
4. **检查下载目录**。群里收的敏感文件用完删掉，回收站也清一遍。

自己的电脑上还有两件小事值得做：**给浏览器设一个锁屏密码**，人离开就锁；**别在多个设备上长期挂着同一个会话**，设备越多，任何一个出问题都会牵连账号。
