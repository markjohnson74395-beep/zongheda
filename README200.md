# 专注开着也不弹：Win11 上 TG 网页版桌面通知的三层叠加排查表（附 6 条真实设置路径）

上周三晚上十点多，一位读者把三张截图发过来：Win11 22H2、专注关着、Chrome 站点权限写着"允许"、Telegram 网页版设置里的通知开关也亮着，可群里的消息一条都不弹，右下角连闪都不闪。他为此换了两台浏览器、重装了一次客户端、清了两次缓存，一个半小时过去，屏幕还是安静的。

这种"每条都在、就是不弹"的情况，九成不是通知坏了。Win 的通知链路上有三层开关是**叠着生效**的：系统对"浏览器这个应用"放不放行、专注/免打扰有没有把它按住、浏览器站点权限允不允许页面把通知递出来。三层里任何一层是关的，屏幕上的表现一模一样——安静。每一层单独看都觉得自己"明明设对了"，难查就难在这里。

## 一、先花一分钟定层，比挨个改设置省事

别急着动手，先看症状属于哪一挂。下面这张表是我实际排查时用的判断口径，一分钟能定层：

| 你观察到的现象 | 最可能卡住的层 | 十秒验证动作 |
| --- | --- | --- |
| 按 Win+N 打开通知中心，**连积压条目都没有** | 系统层：应用没被放行，或策略把通知关了 | 设置 → 系统 → 通知，看浏览器条目是否在列表里、开关是否发灰 |
| 通知中心里有条目，桌面**没横幅、没声音** | 专注层，或系统里把"通知横幅"单独关了 | 展开浏览器条目，看"通知横幅""播放声音"两个勾 |
| 地址栏左侧图标带**斜杠或红叉** | 浏览器站点权限层 | 点图标看是否有"通知：已阻止" |
| 平时正常，**一投屏 / 一进全屏就哑** | 专注的自动规则 | 设置 → 系统 → 专注，看三条自动规则 |

不弹有三种完全不同的修法，先把层定住，只改那一处，改完立刻验证。三层分别怎么走，站上的分层操作配了截图，可以对着 [Telegram网页版使用说明](https://tlgrkg-web.com) 的通知部分一起看。

## 二、三层叠加排查表：五个位置，一个都别跳

这张表建议截图存手机，换电脑、装新浏览器时照点一遍，五分钟封顶：

| 层 | 具体位置（Win11 路径） | 被关掉时你会看到 | 恢复动作 |
| --- | --- | --- | --- |
| ① 系统 · 应用级 | 设置 → 系统 → 通知 → 展开 Chrome / Microsoft Edge 条目 | 通知中心干干净净，什么都没留下 | 勾上"通知横幅""播放声音""显示通知预览" |
| ② 系统 · 全局 | 组策略"关闭通知"、注册表 `ToastEnabled` | 通知页开关发灰，或开了也不生效 | 策略改"未配置"，`ToastEnabled` 改回 1 |
| ③ 专注 · 手动 | 设置 → 系统 → 专注 → 优先模式 | 有条目但不弹横幅、不出声 | 切到"关闭" |
| ④ 专注 · 自动规则 | 同页下方：复制显示时 / 玩游戏时 / 全屏应用时 | 只在特定场景哑，别的时候正常 | 关掉命中的那条规则 |
| ⑤ 浏览器站点权限 | `chrome://settings/content/notifications` | 页面根本不发起通知请求 | 从"不允许"列表移除站点，刷新页面 |

表里 ③④ 最容易被跳过，因为它们不在"通知"页里，而在隔壁的"专注"页，很多人压根没点进去过。

## 三、系统层：一个"通知"入口下面其实有三件事

按顺序点，别跳步：

1. `Win + I` 打开设置 → **系统 → 通知**，确认最上面的"通知"总开关是开的。
2. 同一页往下找"来自应用和其他发送者的通知"，在列表里定位到你用的浏览器（Chrome、Edge、Firefox 各是独立一条），点右侧箭头展开。
3. 展开后把"通知横幅""播放声音""显示通知预览"三个勾全点上。只勾了通知中心不勾横幅，就是"有记录、不弹窗"的经典组合。
4. 同一页底部还有"在锁屏上显示通知""允许通知播放声音"这类开关，按需打开；投屏或外接屏时这几项的表现跟单屏不一样。
5. 公司电脑另说。`gpedit.msc` → 用户配置 → 管理模板 → "开始"菜单和任务栏 → 通知 → "关闭通知"，如果被设成"已启用"，你在设置里看到的开关会是灰的，怎么点都不动。这种情况改设置没用，得找 IT，或用注册表兜底：`HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\PushNotifications` 下的 `ToastEnabled` 改成 1（DWORD），改完注销重新登录。
6. 还有一处常被忽略：同一路径下的 `NoToastApplicationNotification`，某些优化工具和精简版系统会把它写成 1，作用是把所有应用的 toast 全关掉——表现就是"设置全对，一条不弹"。

## 四、专注：Win10 叫专注助手，Win11 把开关挪了地方

"设了专注就一条不弹"，是这套问题里最标准的答案，但两个版本的入口不一样，按老教程找会找不到。

**Windows 10** 在 设置 → 系统 → **专注助手**，三档可选：关闭、仅优先通知、仅闹钟。选"仅优先通知"时，只有"优先列表"里的应用能弹，而浏览器默认不在这个列表里——所以你哪怕在 Chrome 里把站点权限设成允许，横幅照样不出现，通知中心里却能看到条目。

**Windows 11 22H2 之后**改成 设置 → 系统 → **专注**，上面是"优先模式"开关，下面是三条自动规则，默认全是开的：

- 当我复制我的显示时
- 当我玩游戏时
- 当我全屏使用应用时

我遇到过一个特别典型的场景：上午给客户投屏做演示，`Win + P` 选了"复制"，第三条自动规则被触发，专注自动打开；演示结束拔掉线，**专注不会自己退回去**。那天下午所有通知都被压着，人还以为是浏览器出了问题。

还有一处藏得更深：`Win + N` 打开通知中心，面板右下角有个月亮的"免打扰"按钮。它属于临时开关，开了之后在"设置 → 系统 → 专注"里看不出任何变化，重启才复位。查了三层都正常、就是不弹的时候，先看一眼这个月亮。

## 五、浏览器权限：写着"允许"也不代表真的能弹

Chrome 和 Edge 的路径几乎一样，把地址栏当地址用就行：

- Chrome：`chrome://settings/content/notifications`
- Edge：`edge://settings/content/notifications`

进去以后看两处。上面"网站可以请求发送通知"必须是开的；下面"允许发送通知"里要有你正在用的站；如果它出现在"不允许发送通知"里，点右侧三个点选"移除"，然后**刷新页面**——站点权限是页面加载时读取的，不刷新等于没改。

地址栏左侧那个小图标是第二处线索：图标上带斜杠或者红叉，说明本站通知被阻止，点开它会有一行"通知"下拉，改成"允许"即可。Firefox 走 `about:preferences#privacy` → 权限 → 通知 → 设置，在列表里删掉被标记为阻止的站点。

再记一个容易误判的：右键标签页 → "将站点静音"。它只掐声音、不掐横幅，勾上之后你会觉得"通知坏了、一点声都没有"，其实横幅一直在弹。恢复方式就是再点一次同一项。各个权限页的位置各家浏览器不一样，站上按浏览器分列了清单，可以对着 [各浏览器通知权限位置](https://tlgrkg-web.com) 找自己那条。

## 六、"我只改了一处就好了"多半是错觉

专注自动规则退出时有延迟，全屏退出要几十秒才恢复。改站点权限的那一分钟里正好赶上它自己恢复，很容易得出"是站点权限的锅"。下次再遇到只改那一处，问题原样还在。

改完一处别急着下判断，用 `Win + N` 看一眼通知中心：**有积压条目**说明系统层放行了、横幅被按住，回去查专注；**连条目都没有**说明系统层没放行，回去查第三节。

## 七、三分钟复检清单（换机、换浏览器后照着点）

1. `Win + I` → 系统 → 通知：总开关开，浏览器条目三个勾全点上。
2. `Win + N` 看右下角月亮有没有亮着，亮着点掉。
3. 设置 → 系统 → 专注：优先模式为关，三条自动规则按你的使用习惯关掉不需要的。
4. 浏览器进 `chrome://settings/content/notifications`，确认站点在允许列表，刷新页面。
5. 让另一台设备发一条消息过来，五秒内出现横幅算过关；点一下横幅要能跳到对应会话，跳不过去通常是"打开链接"权限或弹窗拦截，与通知无关。

## 记三个位置，比背十个开关管用

下次再遇到"一条都不弹"，只要记住三行：**设置 → 系统 → 通知**（应用放行）、**设置 → 系统 → 专注**（包括那三条会自动打开的规则）、**`chrome://settings/content/notifications`**（站点许可）。三层从下往上过一遍，绝大多数情况在第二层就结束了。

这三层里最该先怀疑的是专注，因为它是唯一会**自己打开**的一层：投屏、全屏看片、插拔外接屏都可能把它打开，而且不会自己关回去。把这三个位置抄在便签上，比装任何排查工具都快。版本对不上、找不到某个开关的时候，回头对照 [Telegram网页版中文指南](https://tlgrkg-web.com) 里的系统权限与专注章节，按同一套顺序核对一遍再动手。
