## **一、先把"打不开"分成四种，别混在一起治**

新手最容易犯的错，是把所有"进不去"都当成同一件事。实际上按现象分至少四类，病灶完全不在一处：

| 你看到的现象 | 大概率卡在哪一层 | 第一件该做的事 |
| --- | --- | --- |
| 页面一片白，地址栏转圈转不停，进度条卡在中间 | **网络层**：线路不通、节点被限速或掐断 | 换一条干净线路，别在原地反复刷新 |
| 页面能打开，但二维码区域空白、按钮点不动 | **入口与缓存层**：进错了站，或本地缓存是坏的 | 手敲地址核对来源，然后清缓存重载 |
| 弹出"你的连接不是私密连接"、证书不受信任、`ERR_CERT_DATE_INVALID` | **证书层**：系统时间错、代理插了自签证书 | 先看系统时间，再看有没有中间人代理 |
| 直接提示找不到服务器、`ERR_NAME_NOT_RESOLVED` | **DNS 层**：域名根本没解析出去 | 换 DNS，用手机流量交叉验证 |

## **二、第一层：入口，先确认你输的地方是对的**

这一层耗时最短，但绝大多数人跳过它。我的做法很简单：**地址栏里手动敲，不从发来的链接进**。

群里转的"网页版直连""免登录入口"短链一律不点。我见过比原版还正规的仿站，标题、配色、帮助文档抄得一模一样，唯一的区别是它会多问你要一步东西——账号密码或额外的验证码。而正常的登录流程里，你要么扫码，要么收一条验证码，**没有任何环节需要你输入账号密码**。

手动输入之后按回车，看两件事：

1. 地址栏左边是不是 `https://`，有没有"不安全"提示；
2. 是不是你印象里的那个域名（从收藏夹进最稳，确认对之后就存下来）。

> **说明**：任何页面只要额外索要账号密码、二次验证码、支付信息，不用犹豫，直接关掉换入口。正常登录流程里不存在这些环节。

顺带说浏览器。这一层的问题里有一半是浏览器太老造成的——二维码渲染不出来、通知弹不出来，都是这个原因。四种主流浏览器脾气不同：

| 浏览器 | 常见毛病 | 我的处理方式 |
| --- | --- | --- |
| Chrome | 标签页开太多，后台连接被挤掉 | 登之前关掉无关标签页，权限和缓存都在这查 |
| Edge | 后台标签被"睡眠"，切回来要重连 | 设为不进入睡眠，通知单独放行 |
| Safari | 跨站跟踪限制会拦掉部分请求 | 对这个站点放宽限制，下载位置单独指定 |
| Firefox | 隐私防护等级高时媒体权限被挡 | 用无痕窗口对照测试，定位是不是扩展问题 |

## **三、第二层：网络，能连上但连不稳才算坑**

网络层的问题有两种，区别很大：**完全连不上**，和**能连上但一直断**。

判断顺序是这样：先开一个跟电报无关的普通网站，能秒开说明本机出口是通的；再回到网页版按 `F5`，如果连握手都握不上，那就是线路不通，换节点，别刷页面。

真正麻烦的是"半通"：页面开了，二维码也出来了，扫完却停在"正在连接"，或者进去几分钟后莫名掉线。这种基本是节点质量或出口 IP 太脏——同一批 IP 上挂的人太多，服务端会掐你。解决办法很朴素：**换一条人少的线路，然后别在登录过程中来回切**。一边登一边切节点，等于自己制造掉线。

## **四、第三层：证书报错，八成是时间或"中间人"**

这就是我开头踩的坑。证书报错看起来最唬人，其实方向只有两个。

### **第一步：看系统时间**

浏览器校验证书有效期靠的是本机时间，偏差超过范围，所有 `https` 站点都会报过期或"不受信任"。我那次就是时间停在两年前，浏览器认为证书还没生效，直接把连接掐了。**证书报错第一件事是看时间，不是换网络。**

### **第二步：查有没有代理在插证书**

时间对的，就想想这台机器装过抓包工具、公司安全客户端，或者某个"加速器"。这类软件在中间解密流量、换上一张自签证书，浏览器自然不认。看证书颁发者那一栏——正常是公共 CA，如果是个陌生名字，那就是中间人在解密。关掉它，或者把证书链装对。

### **第三步：别硬点"继续访问"**

这一步很多人图快。公用电脑、酒店网络这种环境里，"继续访问"意味着放弃校验，后面扫的码、输的验证码都可能被人看到。宁可换条线路重来。

## **五、第四层：DNS，和那些"看起来像网络"的问题**

DNS 层最典型的表现是"找不到服务器"，域名根本没解析出去。处理方式：把本机 DNS 换成公共解析（`223.5.5.5` 和 `8.8.8.8` 各填一个），然后清一次本机 DNS 缓存再试。

容易搞混的点在这里——**DNS 出错经常长得像网络出错**。白屏、转圈、最后超时，可能不是线路不通，而是解析到的地址是错的。区分办法是换一台设备用手机流量打开同一页面：手机能开、电脑不能，问题就在解析或缓存上，不在线路。

顺手把本地缓存一起处理掉，缓存坏了也会装成网络问题：

1. 清"缓存的图片和文件"和"Cookie 及其他站点数据"——注意 **Cookie 一清，登录状态就没了**，得重新扫码；
2. 用无痕窗口打开同一页面，无痕能进说明是扩展或缓存的问题；
3. 把广告拦截、脚本管理这类扩展临时全关，它们会把网页版依赖的请求当广告拦掉；
4. 重启一次浏览器，让设置生效。

## **六、登进去之后，这几项顺手配掉**

排查花的时间通常比配置多，能一次弄完的别拖。进"设置 → 语言"找中文（简体）；浏览器缩放先用 `Ctrl + 0` 复位到 100% 再调字号，不然排版会歪。桌面通知要过两道权限——系统允许浏览器发通知、浏览器允许这个站点发通知，缺一道都不弹。文件默认往"下载"文件夹扔，群里的东西一天几十个就是一锅粥，最好单独指定目录，文件名带上客户名和日期。

## **七、我的排查顺序清单（照着走，别跳步）**

1. **核入口**：手敲地址或从收藏夹进，确认 `https://`，不点别人转的短链。
2. **看时间**：系统时间和现实差得多不多，差得多先校准。
3. **换无痕**：无痕能进，就是缓存或扩展的问题，别再去动网络。
4. **清缓存**：清完重载，接受登录状态丢失的代价。
5. **关扩展**：广告拦截、脚本管理、隐私防护逐个关掉对照。
6. **换线路**：前面都干净还不行才动线路，换完别中途再切。
7. **查解析**：报"找不到服务器"就换 DNS、清缓存，用手机流量交叉验证。
8. **查权限**：通知不弹、文件下不了，去浏览器的站点权限里找。

这套顺序的逻辑是**从零成本到高成本**：核入口、看时间几乎零成本，换线路可能影响你别的活。按这个走，九成问题在前三步就解决了。
