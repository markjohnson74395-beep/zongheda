## **二、三个平台版本对照：你到底该下哪个**

这一步最容易出错，尤其 Mac 用户——不少人看着自己电脑是 MacBook 就直接下 Mac 版，装到一半报"不受支持"，原因是芯片架构不对。

| 平台 | 当前版本 | 更新日期 | 适用系统 / 处理器 | 安装包形式 | 适合谁 |
| --- | --- | --- | --- | --- | --- |
| Windows 版 | V9.20 | 2026-09-18 | Windows，分 64 位 / 32 位 | `.exe` | 绝大多数人，电脑连 iPhone/iPad 做管理、导资料、刷机 |
| Mac 版 | V9.10 | 2026-09-18 | macOS，分 Apple 芯片 / Intel | `.dmg` | 苹果电脑用户，注意先确认芯片类型 |
| Linux 版 | V9.02.009 | 2026-08-19 | Debian/Ubuntu 系与 RPM 系 | `.deb` / `.rpm` | 用 Linux 桌面又要管 iPhone 的人，依赖需按发行版补 |

- **Windows**：右键"此电脑"→ 属性 → 看"系统类型"。写"64 位操作系统"就下 64 位，只有明确 32 位才下 32 位。**别凭电脑新旧猜**，有些老机器装的是 32 位系统。
- **Mac**：点左上角苹果图标 → "关于本机" → 看"芯片"。Apple M 系列下 Apple 芯片版，显示 Intel 就下 Intel 版。
- **Linux**：Debian/Ubuntu 用 `.deb`，Fedora/CentOS/openSUSE 用 `.rpm`。依赖缺什么补什么，别硬装。

## **三、Windows 版安装实测：五步从下载到认出设备**

Windows 是绝大多数人的场景，这套流程我走过几十遍，照着做基本不会卡。

### **第一步：别关杀软本体，只处理下载提示**

下载 `.exe` 时浏览器或 Defender 可能弹"此文件不常见，是否保留"，这是新版本没积累够信誉导致的，确认来源没问题就选"保留"。**但防护不要整个关掉**——正常安装不需要你关杀软。

### **第二步：以管理员身份运行安装包**

右键安装包 →"以管理员身份运行"。爱思助手装的时候要一并装苹果设备驱动，普通权限装不进去，后面就会"插上手机没反应"。

### **第三步：安装路径别放系统盘深处**

默认路径就行。要改也别选带中文和空格的深层目录，个别版本的驱动注册会在这里出问题。

### **第四步：等驱动装完，别急着点下一步**

中途有一个装驱动的环节（苹果设备驱动 / USB 相关组件），可能弹一两次系统确认框，都点"是"。**这一步被跳过，就是九成"识别不到设备"的根因。**

### **第五步：打开软件，再插手机**

先开软件后插线。手机屏幕会弹"要信任此电脑吗"，点"信任"并输锁屏密码。软件里出现型号、容量、电量、序列号，才算真正连上。

## **四、装完连不上？按这五层往下查**

这个问题的排查顺序我固定了，从上往下走，别一上来就怀疑软件坏了：

1. **数据线**。只充电的劣质线是头号元凶，换根原装或带数据传输的线，能解决一半问题。
2. **USB 口**。前置口、Hub、扩展坞都不可靠，直插机箱后面板。
3. **手机端的"信任"**。没弹窗或点过"不信任"，去"设置 → 通用 → 传输或还原 iPhone → 还原位置与隐私"重置再重插。
4. **Windows 驱动**。设备管理器里看有没有黄色感叹号，有就重装驱动（重跑一遍安装包最省事）。
5. **软件版本**。iOS 升级后旧版工具跟不上是常事，回 [爱思助手各平台版本入口](https://www.yo-yo-usa.com) 看当前版本，该更新就更新。

## **六、刷机与固件：这是唯一"可能回不去"的操作**

前面那些操作出错最多重来一次，刷机不是。把风险控制写在这几条上：

1. **先备份，且验证备份可读**。刷机分"保资料"和"不保资料"，但"保资料"不等于零风险——卡在中间、断电、固件不匹配，资料都可能回不来。
2. **固件按设备型号选**。同一个 iOS 版本，不同机型的固件文件不一样，下错了轻则刷不进去，重则卡恢复模式。
3. **别盲目升级或降级**。降级要看官方签名是否还开着，签名关了就是刷不回去，没有后悔药。
4. **中途别拔线、别让电脑休眠**。刷机过程断电事故率最高，笔记本先把电源插上，电源计划改成不休眠。
5. **卡在恢复模式先别慌**。多数是驱动或线材问题，退出重来一次往往就好，别连着刷第二遍。

## **七、常见问题与避坑清单**

**Q：Windows 到底选 32 位还是 64 位？**
看"系统类型"。64 位系统选 64 位版本，只有系统明确写着 32 位才选 32 位。选错的表现是装到一半报不兼容。

**Q：Mac 上装完提示无法打开？**
先确认芯片版本下对了（Apple 芯片 / Intel）。再在"系统设置 → 隐私与安全性"里允许这次打开，别去改系统全局安全策略。

**Q：Linux 版装完命令找不到？**
`.deb` 用 `sudo dpkg -i 包名.deb` 装，缺依赖再 `sudo apt -f install` 补；RPM 系用 `sudo rpm -ivh 包名.rpm`。依赖问题是 Linux 上最常见的失败原因，不是软件坏了。

**Q：手机插上电脑只充电，软件没反应？**
按第四节五层顺序查，重点看数据线和"信任此电脑"。

**避坑清单，五条：**

1. 搜索结果里带"高速下载""极速安装"的按钮，一律不点。
2. 安装时把所有"推荐安装""附加组件"的勾全部取消。
3. 装完先确认设备能被识别，再去动相册和通讯录。
4. 刷机、恢复、批量删除之前，必须有一份验证过的备份。
5. 二手机验机结果只当参考，别当成交易依据。
